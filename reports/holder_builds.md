Listed: holders that aren't funds (by a name list), whose latest stake is 7% or more and at least two points above where the window starts, and who haven't ceased. Notices that are scanned images were read by OCR, so names and figures can be misread: each line is a pointer to read the notices, not a fact. This is a simulation and not financial advice.

Each build is checked for links to the board or to another holder: a director's name in the holder's notices, the holder named in a director's interest notice, or the same street address as another holder that isn't a fund. A linked holder can usually take control without paying other holders a premium (TOT and EGH, Nov 2026), so outside buyers come first. Scanned notices can't be checked this way, so no link found isn't proof of none. The last column gives the company's status in research/picks/INDEX.md if it has already been looked at: check that file before starting work on any line.
